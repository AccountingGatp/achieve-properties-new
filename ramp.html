SOP: Ramp CC Import into ResMan

SOP: Ramp CC Import into ResMan

Achieve Properties | Monthly Bank Reconciliation Workflow

1. Purpose & Scope

This SOP covers the complete end-to-end process for posting Ramp credit card transactions into ResMan — from generating the import sheet using Claude, to uploading and posting the journal entry in ResMan. This process runs monthly for each property entity.

This SOP covers two phases:

  • Phase A — Generate the import CSV using Claude

  • Phase B — Import and post the journal entry in ResMan

2. Process Overview

Each Ramp CC transaction is recorded in ResMan as a two-line journal entry:

Line Entry Type GL Side GL Account
Line 1 Expense (the purchase) DEBIT Accounting Category Code from Ramp
Line 2 CC Payable (amount owed on card) CREDIT Property CC GL (e.g. 1050-1 for Rio Springs)

NOTE: Every transaction must have both lines — one debit and one matching credit — so the journal is balanced before posting.

PHASE A — Generate the Import CSV (using Claude)

4. Prerequisites — Before You Start

  • Download the Ramp CC statement CSV for the billing period you need to import

  • Confirm all transactions in Ramp are coded (Accounting Category Code column is filled in)

  • Have the General Import Template CSV filename handy for reference

  • Open Claude (claude.ai or Cowork desktop app)

5. Generate the Import Sheet in Claude

STEP 1 Open Claude and paste the standard prompt

COPY THIS PROMPT TO CLAUDE — Attach the Ramp CSV before sending

I am uploading a Ramp credit card statement CSV. Please generate

the ResMan accounting import sheet using the following rules:

STEP 1 — FILTER ROWS

- Only include rows where Type = "Transaction"

- Skip all rows where Type is anything else (transfers, payments, etc.)

- Skip any row where the Accounting Category Code column is blank

and list those separately as flagged/uncoded transactions

STEP 2 — BUILD TWO LINES PER TRANSACTION

For every valid transaction, create exactly two rows in the import file:

LINE 1 (Expense — Debit):

- Property Abbreviation : derived from Ramp Location (letters only, no numbers)

- Date : Transaction Date

- GL Account Number : Accounting Category Code from Ramp

- Description : Merchant Description from Ramp

- Debit : Amount

- Credit : leave blank

- Accounting Basis : Both

- Line-Item Description : Merchant Description (same as Description)

- Reversal Date : leave blank

- Reference : leave blank

LINE 2 (CC Payable — Credit):

- Property Abbreviation : same as Line 1

- Date : same as Line 1

- GL Account Number : property CC GL code (see mapping below)

- Description : Merchant Description (same as Line 1)

- Debit : leave blank

- Credit : Amount (same as Line 1 Debit)

- Accounting Basis : Both

- Line-Item Description : Merchant Description (same as Description)

- Reversal Date : leave blank

- Reference : leave blank

STEP 3 — PROPERTY &amp; GL MAPPING

Use this table to map Ramp Location to Property Abbreviation and CC GL:

Ramp Location | Property Abbr. | CC Payable GL

------------------|----------------|---------------

Rio Springs | RI | 1050-1

Morgan Manor | MM | 1075-1

Salado Creek | SA | 1071-1

Istana | IS | 1092-1

Green Oaks | GO | 1086-1

University Cove | UC | 1066-5

Mila | ML | 1044-1

Valencia | VA | 1060-4

STEP 4 — OUTPUT FORMAT

- Output a CSV with exactly these column headers in this order:

Property Abbreviation, Date, GL Account Number, Description,

Debit, Credit, Accounting Basis, Line-Item Description,

Reversal Date, Reference

- Output a separate flagged CSV for missing GL transactions with:

Date, Amount, Merchant Description, Ramp Location, External ID, Issue

- Name the import file: Ramp_CC_Import_[PropertyCode]_[YYYYMM].csv

- Name the flagged file: Ramp_CC_FLAGGED_[PropertyCode]_[YYYYMM].csv

- Confirm that Total Debit = Total Credit (balanced) in the summary

NOTE: The prompt above is embedded in this SOP. Copy it fresh each month — do not modify the wording. Attach the Ramp CSV before sending.

STEP 2 Attach the Ramp CSV and send

Before clicking Send, attach the Ramp CC statement CSV file to the Claude message.

  • Click the paperclip / attachment icon in Claude

  • Select the downloaded Ramp CSV (e.g. 2026-02-10-2800-w-hutchins-pl-llc.csv)

  • Click Send

STEP 3 Review Claude's output

Claude will generate two files:

  • Ramp_CC_Import_[Code]_[YYYYMM].csv — the import file ready for ResMan

  • Ramp_CC_FLAGGED_[Code]_[YYYYMM].csv — any uncoded transactions (if any)

Before downloading, verify Claude's summary shows:

  • Total Debit = Total Credit (balanced)

  • Transaction count matches your expectation

  • Correct property abbreviation and CC GL code

IMPORTANT: If any transactions appear in the FLAGGED file, do NOT proceed with the import until those transactions are coded in Ramp. Go back to Ramp, assign the GL codes, re-download the statement, and re-run Claude.

STEP 4 Download and save the import file

Download both files from Claude to your computer.

  • Save the import CSV to your designated monthly reconciliation folder

  • Naming convention: Ramp_CC_Import_[PropertyCode]_[YYYYMM].csv

  • Example: Ramp_CC_Import_RI_202602.csv

NOTE: Do not open and re-save the CSV in Excel before importing — this can alter date formats and cause import errors. If you need to review it, open it in read-only mode or Google Sheets.

PHASE B — Import into ResMan

6. Import Column Mapping

The import CSV columns map to ResMan journal entry fields as follows:

CSV Column ResMan Field Notes
Property Abbreviation Entity / Property Must match ResMan property code exactly
Date Journal Date Transaction date from Ramp
GL Account Number Account Expense GL or CC Payable GL
Description Description Merchant name from Ramp
Debit Debit Amount Positive dollar amount on expense line
Credit Credit Amount Positive dollar amount on CC payable line
Accounting Basis Basis "Both" — applies to cash and accrual
Line-Item Description Line Description / Memo Same as Description

7. ResMan Import Steps

STEP 1 Log in to ResMan and select the property

  1. Log in to ResMan at your company's ResMan URL

STEP 2 Navigate to Journal Entry Import

  1. From the main menu, go to: Accounting

  2. Select: Journal Entries

  3. Click: Import (or Upload Journal Entries — the label may vary by ResMan version)

NOTE: If you do not see an Import option, confirm your user role has Journal Entry import permissions. Contact your ResMan administrator if needed.

STEP 3 Upload the CSV file

  1. Click Browse or Choose File

  2. Navigate to and select your saved import CSV file (Ramp_CC_Import_[Code]_[YYYYMM].csv)

  3. Click Upload / Next

STEP 4 Map columns (if prompted)

If ResMan shows a column-mapping screen, match the CSV headers to ResMan fields using the table in Section 6. The column names in the CSV are already formatted to match ResMan's expected headers — mapping should be automatic.

If mapping is manual, set each field as follows:

  • CSV: Property Abbreviation → ResMan: Entity / Property

  • CSV: Date → ResMan: Journal Date

  • CSV: GL Account Number → ResMan: Account

  • CSV: Description → ResMan: Description

  • CSV: Debit → ResMan: Debit Amount

  • CSV: Credit → ResMan: Credit Amount

  • CSV: Accounting Basis → ResMan: Basis

  • CSV: Line-Item Description → ResMan: Line Description / Memo

STEP 5 Review the preview and verify balance

Before posting, ResMan will show a preview of the journal entries. Verify:

  • Row count = 2 rows per transaction (should be an even number)

  • Total Debits = Total Credits (journal must be balanced — ResMan will block posting if not)

  • Spot-check 2-3 entries: confirm property, date, GL, and merchant name look correct

  • Dates fall within the correct posting period

IMPORTANT: Do not post if Total Debits do not equal Total Credits. Go back to the import file, find the missing line, correct it, and re-upload.

STEP 6 Set journal description and post

  1. Enter a Journal Description (header memo) for the batch, e.g.:

Ramp CC — Rio Springs — February 2026

  1. Select the correct Posting Period / Accounting Period

  2. Click Post (or Submit for Approval if your workflow requires manager approval)

  3. Confirm the success message — note the Journal Entry number for your records

STEP 7 Verify the posted journal in ResMan

  1. Go to Accounting → Journal Entries → Search / View All

  2. Locate the journal entry you just posted using the Journal Entry number or date

  3. Open it and confirm:

  • All lines are posted (no errors or pending lines)

  • Debit total and Credit total match

  • GL accounts and property match the source Ramp data

  1. Screenshot or save the confirmation for your records

8. Handling Flagged / Uncoded Transactions

If Claude generates a FLAGGED file with uncoded transactions, handle them as follows:

  1. Open the FLAGGED CSV — it lists the date, amount, merchant, and External ID of each uncoded transaction

  2. Log in to app.ramp.com → Transactions → find each flagged transaction by date/merchant

  3. Assign the correct Accounting Category (GL code) to each transaction in Ramp

  4. Re-download the Ramp CSV for the same period

  5. Re-run Claude using the same prompt with the updated CSV

  6. Verify the flagged transactions no longer appear in the new FLAGGED file

  7. Import the corrected file into ResMan as a separate journal entry batch, or combine with the original if not yet posted

11. Journal Entries template (added step)

Added in the app. It replaces the Section 6 column list.

In ResMan choose Type = Journal Entries and pick the Property in the dropdown. The file has no property column. Its columns are: Date, GL Account Number, Description, Debit (Enter as positive), Credit (Enter as positive), Accounting Basis, Accounting Book, Department. Use one file per property.

10. Missing GL: fill from the General Ledger (added step)

Added in the app, not in the original SOP document.

  1. Export the property General Ledger from ResMan (all months of the year) as .xlsx and add it in the General Ledger box.
  2. For a transaction with no Accounting Category Code, the app first looks for the same merchant coded elsewhere in the Ramp file. If none, it uses the GL your ledger history shows for that vendor, and uses the Ramp memo to choose between several.
  3. Each filled GL is marked High, Medium or Low confidence on the GL assigned tab. Review the Low ones. A vendor split across many GLs, such as Home Depot, is usually Low.
  4. Only merchants with no ledger history stay flagged. Code those in Ramp.

9. Bill check: AP Aging and Invoice Detail (added step)

This step was added in the app. It is not in the original SOP document yet.

Before posting a Ramp payment as an expense, confirm there is not already a bill for it in ResMan. Otherwise the expense is booked twice.

  1. In ResMan run AP Aging Detail (as of today) and Invoice Detail (1/1 to today) for each property. Save them as .xlsx.
  2. Drop both reports into the app with the Ramp CSVs. A .zip of them works too.
  3. The app matches each Ramp payment to a bill by vendor name and exact amount, and marks it:
    • Open bill found: the payment must be closed against that bill in ResMan, paid with the property CC GL. The app leaves it out of the import file.
    • Bill already entered: the bill is in Invoice Detail and no longer open. Check it was not paid another way before importing.
    • No bill found: it imports as the normal two-line journal entry. If it is a vendor invoice, create the bill in ResMan.
  4. Open the Bill check tab on each card, or download the Bill check CSV or workbook tab, and work through it.
